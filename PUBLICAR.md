# Publicar e conferir o app

O código está preparado para publicação. Não há URL publicada confirmada nesta etapa.

1. Abra https://share.streamlit.io e entre com a conta GitHub `goodguto`.
2. Crie um app a partir do repositório `goodguto/AVD-20262-pratica-streamlit`.
3. Selecione a branch `main`, o arquivo `app.py` e Python 3.12 nas configurações avançadas.
4. Publique e acompanhe a instalação de `requirements.txt`. Não há segredos necessários ao app.
5. Depois de abrir a aplicação, copie a URL real para o README.
6. Abra essa URL em janela anônima, sem login, e confira as duas abas.
7. No laboratório, teste seleção de variáveis, slider, histogramas e heatmap.
8. Nos indicadores, teste nacionalidade, posição e idade. Confira se os três cartões e os três gráficos mudam juntos. Teste também um recorte vazio.
9. Registre URL, data, navegador, resultado e eventuais problemas em `entregas/TESTE_PUBLICADO.md`.

Os 27 testes locais não substituem essa conferência da versão publicada.
